🪟 WindowsAppPlayer

runs 32-bit Windows apps in your browser — Wine + WebAssembly, no VM, nothing uploaded Boxedwine ↗

1 · Load an app

Drop a .exe, .msi, or .zip here
or click to browse — files stay on this machine

2 · Engine

Not sure? Just Run — the engine is picked automatically from the EXE header.

3 · Run

Pick an app, or try the demo. First 32-bit run downloads the Wine system (~50 MB, once).
Best with classic Win32 apps from ~1995–2010 on the 32-bit engine; wine64 handles newer 64-bit apps (still experimental). Emulated speed, no GPU acceleration.
